# Rocio Delgado — Portfolio

Single-file site (`index.html`) ready for GitHub Pages.

## Publish (5 minutes)

1. On GitHub, create a repository named **`<your-username>.github.io`** (gives you `https://<your-username>.github.io`). Any other name works too — the URL becomes `https://<your-username>.github.io/<repo-name>`.
2. Upload `index.html` (and this README) to the repository root: **Add file → Upload files → Commit**.
3. Go to **Settings → Pages**. Under *Build and deployment* choose **Deploy from a branch**, branch **main**, folder **/ (root)** → **Save**.
4. Wait ~1 minute, then open the URL shown on that page.
